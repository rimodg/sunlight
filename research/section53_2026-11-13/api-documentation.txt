OCDS API
You can download notices in Open Contracting Data Standard (OCDS) JSON format using our API. Notice fields are mapped to OCDS version 1.1.5 with extensions as
defined by the Open Contracting Partnership
.

XML downloads
The same notice data is also available to download from the data.gov.uk website or using their API. Daily Zip files contain an XML file for each notice.
