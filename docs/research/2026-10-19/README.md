`repository-manifest.json` pins eight reviewed official repositories.
`reviewed-documents.json` lists fourteen primary artifacts with commits/locators
and SHA-256 hashes. `retrieval-manifest.json` and `visual-source-manifest.json`
record initial direct retrieval attempts, including failed paths later resolved
through the official Git repositories. `source-file-hashes.json` records extra

source or fully reviewed. The exploratory OpenAI OpenAPI download was truncated

investigative accuracy.

No live provider records, private credentials or institutional confidential
material were added to these research files. Publication of a specification or
successful Git retrieval does not establish API entitlement, real-time data or
complete economic coverage.
